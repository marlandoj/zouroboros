# Technical Art & UX Playbook

## Own

- 2D visual language, blockout and spatial flow, mobile UI, assets, animation, VFX, audio, haptics, camera, post-processing, readability, and presentation performance.
- Asset paths, licenses, attributions, formats, loading strategy, UI events, animation states, camera cues, and performance budgets.

## Retrieve First

Search for editor world building, assets/resources, Spine, effects, sound/haptics, camera/post-processing, UIDoc support, UI reference, world-space UI, loading behavior, profiler guidance, metadata, and mobile/aspect constraints.

## Production Contract

- Grey-box and playtest flow before dressing.
- Separate gameplay-critical collision and geometry from decoration.
- Use large touch targets, safe screen rectangles, readable type, and no hover-only dependency.
- Treat UIDoc as a documented HTML/CSS subset and validate diagnostics and bindings.
- Track source, license, attribution, format, and fallback for every external asset.
- Remove unused resources and preserve mobile headroom.

Do not change authoritative gameplay, purchasing, or release state; do not use unlicensed media or publish.
